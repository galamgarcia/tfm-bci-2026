# Desarrollo de un sistema de interacción BCI aplicado a videojuegos

Diseño e implementación de un sistema de interacción basado en interfaces cerebro-computadora (BCI) aplicado al control de videojuegos. El proyecto se centra en la obtención y procesamiento de señales de la actividad del lóbulo frontal mediante un sensor no invasivo, con el objetivo de identificar patrones asociados a estados cognitivos y traducirlos en comandos de interacción dentro del entorno de juego.

Como parte del proyecto se desarrolla BIT, un videojuego de plataformas 2D diseñado específicamente para explorar la integración de estas señales como mecánicas jugables. El jugador controla a Bit, una pequeña entidad digital que intenta avanzar a través del sistema en el que existe y, eventualmente, encontrar una forma de escapar de él.

La interacción combina diferentes modalidades de entrada. El movimiento de la cabeza permite desplazar a Bit, el pestañeo se utiliza como acción de salto y determinados estados cognitivos, como la relajación y la concentración, modifican tanto sus capacidades como el propio entorno.
